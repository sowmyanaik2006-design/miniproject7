MINIPROJECT 7
 "WASTE CLASSIFICATION USING DEEP LEARNING"

Project Overview:
  Project Overview

Waste Classification Using CNN is a deep learning project that classifies waste images into six categories: 
cardboard, glass, metal, paper, plastic, and trash. 
It uses a Convolutional Neural Network (CNN) built with TensorFlow and Keras to identify waste types from uploaded images. 
A Streamlit web application provides a simple interface for uploading images and viewing the predicted category and confidence score.
The project aims to demonstrate how artificial intelligence can support waste sorting and recycling.
